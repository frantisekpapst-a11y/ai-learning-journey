# AI Data Analyst Agent

> AI Data Analyst Agent is a platform-agnostic analytical framework designed to perform structured business data analysis using a standardized workflow.
>
> This repository contains both the functional specification of the agent and a complete reference case study demonstrating the expected analytical output.

---

## Overview

AI Data Analyst Agent vznikl jako součást projektu **AI Learning Journey**.

Cílem projektu bylo navrhnout analytického AI agenta, který nefunguje pouze jako generátor textu, ale dodržuje konzistentní analytické workflow podobné práci profesionálního datového analytika.

Agent klade důraz na:

- transparentnost,
- reprodukovatelnost,
- kvalitu dat,
- auditovatelnost,
- business interpretaci výsledků,
- jasné oddělení faktů od předpokladů.

# Analytical Workflow

Agent postupuje podle standardizovaného workflow:

1. Business Understanding
2. Data Collection
3. Data Quality Assessment
4. Data Cleaning
5. Analysis
6. Validation
7. Reporting

Každý krok je dokumentován a reprodukovatelný.

---

# Design Principles

Projekt je postaven na následujících principech:

- Evidence-Based Analysis
- Data Quality First
- Transparency
- Reproducibility
- Traceability
- Auditability
- Business Value

# Purpose

Tento projekt neslouží jako hotový software ani jako automatizovaný AI nástroj.

Jeho cílem je ukázat návrh profesionálního AI analytického workflow, které lze použít jako základ pro tvorbu vlastních AI agentů nebo analytických asistentů.
