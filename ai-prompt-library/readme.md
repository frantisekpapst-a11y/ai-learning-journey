---

# O knihovně

Tato knihovna obsahuje vlastní prompty vytvořené během studia AI.

Nejde o sbírku jednorázových dotazů, ale o opakovaně použitelné profesionální workflow, která lze využít při každodenní práci datového analytika.

Každý prompt je průběžně rozšiřován a vylepšován na základě získaných zkušeností.

---

# Struktura promptů

Každý prompt obsahuje:
- účel
- vhodné použití
- profesionální prompt
- možnosti rozšíření
- lessons learned

# Lessons Learned

Prompt není otázka.

Prompt je kvalitně připravené business zadání.

Čím kvalitnější zadání vytvoříme, tím kvalitnější výstup od AI získáme.
