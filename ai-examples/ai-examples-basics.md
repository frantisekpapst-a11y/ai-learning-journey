# Prompt Improvement Examples

Praktické ukázky zlepšování promptů.

# Example 1 — Power BI Dashboard

## Špatný prompt

Navrhni dashboard.

---

## Lepší prompt

Navrhni Power BI dashboard pro e-shop.

---

## Profesionální prompt

Jsi senior datový a BI analytik.

Cílem je navrhnout Power BI dashboard pro top management e-shopu.

Máme k dispozici:
- datum objednávky
- produkt
- kategorii
- cenu
- množství
- zákazníka
- region.

Navrhni:
- KPI
- grafy
- slicery
- tabulky
- DAX míry
- rozložení dashboardu

Výstup připrav jako Markdown.

U každého návrhu stručně vysvětli business přínos.

Pokud některé informace chybí, nejprve vypiš předpoklady a nevymýšlej si data.

---

## Co se zlepšilo

✅ role
✅ cíl
✅ kontext
✅ omezení
✅ formát
✅ zdůvodnění

# Example 2 — SQL

## Špatný prompt

Napiš SQL.

---

## Lepší prompt

Napiš SQL dotaz pro revenue.

---

## Profesionální prompt

Jsi senior SQL developer.

Používáme Microsoft SQL Server.

Navrhni SQL dotaz, který spočítá měsíční revenue podle regionů.

Použij CTE.

Přidej komentáře.

Navrhni možné indexy.

Vysvětli optimalizaci.

---

## Co se zlepšilo
- technologie
- databáze
- business cíl
- optimalizace
- dokumentace

# Example 3 — Excel

## Špatný prompt

Jak udělám kontingenční tabulku?

---

## Lepší prompt

Jak vytvořím kontingenční tabulku?

---

## Profesionální prompt

Jsi Excel konzultant.

Mám tabulku prodejů obsahující:
- datum
- produkt
- region
- tržby

Potřebuji vytvořit kontingenční tabulku pro management.

Navrhni:
- rozvržení
- filtry
- slicery
- graf
- doporučené KPI

Výsledek popiš krok za krokem.

# Example 4 — Business Analysis

## Špatný prompt

Pomoz mi.

---

## Profesionální prompt

Jsi senior business analytik.

Nejprve analyzuj problém.

Pokud některé informace chybí, polož mi doplňující otázky.

Teprve potom navrhni řešení.

Odděl:
- fakta
- předpoklady
- doporučení
- rizika

---

# Lessons Learned

Profesionální prompt:
- definuje roli
- stanovuje cíl
- poskytuje kontext
- obsahuje omezení
- určuje formát
- požaduje zdůvodnění
- omezuje halucinace
- podporuje iteraci
